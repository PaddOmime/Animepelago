# Animepelago Setup Guide

1. Put `animepelago.apworld` into your Archipelago `custom_worlds` folder.
2. Create a YAML for Animepelago (Options Creator or the template) and generate your multiworld.
3. Open the Animepelago web client, enter the server address, your slot name and password, and start guessing.

## Note on local servers
The website uses https, so browsers only allow encrypted connections from it.
Rooms on archipelago.gg always work. For a server on your own PC, open the client locally.
