# Animepelago Einrichtung

1. Lege `animepelago.apworld` in den Ordner `custom_worlds` deiner Archipelago-Installation.
2. Erstelle eine YAML für Animepelago (mit dem Options Creator oder der Vorlage) und generiere deine Multiworld.
3. Öffne den Animepelago-Webclient, gib Server-Adresse, Slot-Namen und Passwort ein und fang an zu raten.

## Hinweis zu lokalen Servern
Die Webseite ist verschlüsselt (https). Browser erlauben ihr deshalb nur verschlüsselte Verbindungen.
Räume auf archipelago.gg funktionieren immer. Für einen Server auf deinem eigenen PC öffne den Client lokal.
